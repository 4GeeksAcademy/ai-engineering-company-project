# Global working rules (project application)

## Scope

Always — every agent session in this repository.

## Standard

Apply the Global Working Rules to this HealthCore project:

1. Maintain `memory-bank/` with active `context.md`, `spec.md`, `progress.md`, `decisions.md`, and `archive/`.
2. Read the four active memory files before substantial work; do not read archives unless asked.
3. Discover and use applicable skills; prefer `skills/pre-delivery-verification` before requested UI/agent-doc commits.
4. Prefer smallest scoped changes; no unrelated refactors.
5. Never commit, push, or open PRs unless the user requests it; never expose secrets.
6. Update `progress.md` (and `decisions.md` when needed) after material work; state next steps before finishing substantial tasks.

HealthCore-specific protected paths and delivery steps in root [`AGENTS.md`](../../AGENTS.md) remain binding.
